## 📖 О проекте

**ПТИ · НовГУ** — неофициальный студенческий портал, созданный для студентов Политехнического института Новгородского государственного университета имени Ярослава Мудрого.

Проект решает главную боль первокурсника — **«Где у меня пара и как туда дойти?»** — и добавляет к этому удобные сервисы: интерактивную карту корпусов, ИИ-помощника по расписанию, тёмную тему, офлайн-режим и многое другое.

> 💡 Проект сделан за 20 дней в стиле **вайб-кодинга**: код генерировался через ИИ-агентов, автор выступал в роли архитектора и продуктового менеджера.

## ✨ Возможности

### 📅 Расписание
- Разделение на **верхнюю и нижнюю неделю** — данные не пересекаются
- Учёт **«до 9 недели»** и **«после 9 недели»** — предметы показываются в нужный период
- Отдельная отметка для **замен** (⚠️ оранжевая карточка)
- Поиск по предмету, преподавателю, аудитории
- Фильтр по преподавателю
- **Скрытие выходных** одним кликом
- **Экспорт в PNG** — для шеринга в чате группы
- **Экспорт в iCal** — для добавления в Google/Apple Calendar
- **Кнопка «Добавить в Google Calendar»** для каждой пары

### 🗺️ Карта корпусов
- Интерактивная **карта Яндекс** с метками корпусов НовГУ
- Всплывающие подсказки с адресами
- **В разработке:** внутрикорпусной навигатор с маршрутами между аудиториями

### 🤖 ИИ-помощник
- **Локальный парсер** — отвечает мгновенно на «Что завтра?», «Когда физика?», «Следующая пара?»
- **GigaChat через прокси-сервер** — для сложных вопросов
- **Голосовой ассистент** — говоришь вопрос, ИИ отвечает голосом
- Ключи **никогда не попадают в браузер** — хранятся на сервере

### 🎮 Геймификация
- **30+ достижений** с 4 уровнями редкости: 🥉 Обычная · 🥈 Редкая · 🥇 Эпическая · 💎 Легендарная
- **Прогресс-бар** сбора ачивок
- **Конфетти** при разблокировке эпических и легендарных достижений
- **Рейтинг группы** — топ-5 студентов по ачивкам
- **Дни рождения** — студенты сами добавляют свои ДР

### 📱 PWA и офлайн
- **Установка на телефон** как нативного приложения
- **Работа без интернета** — расписание доступно офлайн
- **Уведомления о парах** — напоминание за 15 и за 5 минут
- **Тёмная тема** с корректными контрастами
- **Адаптивная вёрстка** — от 320px до 4K

### 🔒 Безопасность
- **Firebase Authentication** — вход только для админа
- **Firestore Rules** с валидацией полей и whitelist доменов для картинок
- **XSS-защита** — все пользовательские данные экранируются
- **Cooldown 30 секунд** на обратную связь — защита от спама
- **Offline-кэш Firestore** через IndexedDB

## 🏗️ Архитектура

Проект состоит из **двух независимых частей**:
┌──────────────────────────────────────┐
│ СТАТИЧНЫЙ САЙТ │
│ Хостинг: reg.ru (pti-novsu.ru) │
│ ├── index.html │
│ ├── manifest.json │
│ ├── service-worker.js │
│ ├── icon-192.svg │
│ └── icon-512.svg │
└────────────┬─────────────────────────┘
│ fetch('/ask')
▼
┌──────────────────────────────────────┐
│ GIGACHAT PROXY │
│ Хостинг: BotHost │
│ └── index.js (Express) │
│ ├── /ask — принимает вопрос │
│ ├── OAuth к Сберу │
│ └── возвращает ответ GigaChat │
│ Secrets: GIGACHAT_AUTH_KEY │
└──────────────────────────────────────┘

**Почему два хостинга?**
- Reg.ru — статика. Дёшево, быстро, надёжно.
- BotHost — сервер. Держит ключи GigaChat в безопасности.

Если proxy недоступен — сайт **продолжает работать** через локальный парсер.

## 🛠️ Технологии

| Слой | Технология |
|------|-----------|
| **Фронтенд** | Vanilla JS, HTML5, CSS3 (без фреймворков) |
| **Прокси-сервер** | Node.js 20, Express 4 |
| **БД** | Firebase Firestore (real-time, offline-кэш) |
| **Авторизация** | Firebase Authentication (Email/Password) |
| **ИИ** | GigaChat API (Сбер) |
| **Карты** | Яндекс.Карты JS API |
| **Погода** | Open-Meteo (3 модели — ICON, GFS, ECMWF) |
| **PWA** | Service Worker, Web App Manifest |
| **Голос** | Web Speech API (recognition + synthesis) |
| **Экспорт** | html2canvas, iCal (ICS) |
